# CCA-F Exam Notes — source meta

Personal, heavily structured study notes for the **Claude Certified
Architect – Foundations** exam. Organized by the five official exam
domains and their task statements, each with a "Shortcut" rule of
thumb plus **Correct / Wrong** decision lists.

**Why it matters:** this is the primary source for the wiki. The
prose is already distilled into exam-style decision rules, so most
wiki pages derive directly from it.

**Coverage:**
- Scope, content outline (domain weights), and the 6 exam scenarios.
- Domain 1 — Agentic Architecture & Orchestration (task statements 1.1–1.7).
- Domain 2 — Tool Design & MCP Integration (2.1–2.5).
- Domain 3 — Claude Code Configuration & Workflows (3.1–3.6).
- Domain 4 — Prompt Engineering & Structured Output (4.1–4.6).
- Domain 5 — Context Management & Reliability (5.1–5.6).

**Caveats:**
- Section headers in the raw file mislabel Domain 3 as "Agentic
  Architecture & Orchestration" — content is actually Claude Code
  config. The wiki uses the correct domain titles from the content
  outline.
- The file embeds many remote (Larksuite) screenshots that are not
  captured here as text. Diagrams that only live in images are noted
  as gaps where relevant.
